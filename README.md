# 晨昏太陽同步軌道 · 3D 幾何實驗室

這是一個專為理解晨昏太陽同步軌道（Dawn–Dusk Sun-Synchronous Orbit）而設計的**互動式幾何示意網站**，不是實際衛星追蹤器。

## 開啟網站

部署至 Vercel 後直接開啟首頁。亦可在本地以現代瀏覽器開啟 `index.html`，但需要可連上 jsDelivr 取得 Three.js。

## 互動方式

- 使用滑鼠拖曳旋轉地球與軌道、滾輪縮放。
- 點選 06:00、10:30、12:00、18:00 比較不同軌道相對於太陽的方向。
- 調整高度，觀察地球／軌道半徑的真實比例，以及不受地球本影影響所需的太陽 β 角。
- 調整一年中的日期，觀察地軸傾斜導致的季節性日照差異。
- 播放衛星沿軌道繞行（示意加速），並顯示衛星目前在陽光或地球陰影內。
- 開啟「疊加其他軌道」，比較相同傾角、不同 LTAN 的軌道。
- 「自訂軌道傾角」允許離開太陽同步條件，探索不同幾何。

## 尺寸與物理假設

- 地球半徑採用 **6,371 km**，球體與軌道的空間半徑按相同尺度建模。
- 紅／黃色軌道分別標示**本影／日照**，地球陰影也在相同空間尺度下繪製。
- 衛星點、太陽光箭頭與線條寬度是刻意放大的介面標記；太陽距離與直徑未依比例顯示。
- 地球本影顯示採錐狀近似，長度與太陽視大小有關。衛星是否進入本影，為簡化計算使用**太陽光平行、地球陰影圓柱**條件；低軌時與真實錐狀本影差異相對小，但不是精密星曆解。
- 使用圓形兩體軌道、重力參數 `398600.4418 km³/s²`。
- 太陽同步傾角依地球 `J2 = 1.08262668 × 10⁻³` 一階節點歲差近似解：
  `Ω̇ = -3/2 × J2 × n × (R/a)² × cos(i)`，目標 `Ω̇ = 2π / (365.2422 × 86400)`。
- 太陽位置用黃赤交角 23.43928° 和均勻視黃經近似；春分近似在一年中的第 80 天。
- 軌道升交點赤經 RAAN 隨全年均速進動；並沒有強迫其與真太陽赤經完全重合。對 LTAN 的選用是**平均太陽時間的近似**，並非精密時角計算。
- 不模擬離心率、歲差高階項、真太陽橢圓軌道、月地擾動、重力場細節、地球大氣消光、半影和碰撞風險。

## 核心幾何

太陽 β 角定義為**太陽方向與軌道平面之間的夾角**，不是軌道傾角 `i`。理想的「正對太陽」軌道平面對應 `|β| = 90°`。

在圓軌道、平行太陽光下，只要 `|β| ≥ asin(R/(R+h))`，就不進入地球陰影。

晨昏 SSO（06:00/18:00）接近這個理想情況，但實際在約 550 km 的 SSO 傾角約 97.6°，加上太陽季節性赤緯變化，**全年不一定保持 |β| = 90°，也不保證全程日照**。
